## 1. Pendahuluan

Platform perangkat lunak merupakan lingkungan tempat aplikasi dikembangkan dan dijalankan. Tiga platform yang umum digunakan adalah Web, Desktop, dan Mobile. Ketiganya memiliki karakteristik berbeda dalam bahasa pemrograman, arsitektur, distribusi, keunggulan, dan keterbatasan.

## 2. Tabel Analisis Komparatif Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, JavaScript, TypeScript | C#, Java, C++, Python | Kotlin, Java, Swift, Dart |
| Arsitektur | Umumnya client-server dan diakses melalui browser | Berjalan pada sistem operasi komputer | Dirancang untuk perangkat bergerak dan dapat terhubung ke server |
| Distribusi | Melalui browser menggunakan URL | Installer atau toko aplikasi | Toko aplikasi atau distribusi langsung |
| Keunggulan | Mudah diakses dan pembaruan dapat dilakukan di server | Dapat terintegrasi dengan sistem operasi komputer | Mendukung layar sentuh dan fitur perangkat seperti kamera serta GPS |
| Keterbatasan | Bergantung pada browser dan koneksi untuk fitur tertentu | Memerlukan instalasi dan memperhatikan kompatibilitas sistem operasi | Memerlukan penyesuaian perangkat, ukuran layar, dan versi sistem operasi |
| Contoh aplikasi | Gmail versi web, Google Docs versi web | Microsoft Word versi desktop, Notepad | WhatsApp Android, Google Maps mobile |

## 3. Pembahasan

Platform Web cocok untuk aplikasi yang ingin diakses melalui browser tanpa mengharuskan pengguna memasang aplikasi desktop secara terpisah. Platform Desktop sesuai untuk aplikasi yang membutuhkan integrasi dengan sistem operasi komputer atau penggunaan sumber daya lokal. Sementara itu, platform Mobile dirancang untuk smartphone dan tablet dengan mempertimbangkan layar sentuh, ukuran layar, serta fitur perangkat.

Pemilihan platform harus disesuaikan dengan kebutuhan pengguna, tujuan aplikasi, keamanan, biaya pengembangan, dan kemudahan pemeliharaan. Tidak ada satu platform yang selalu paling baik untuk semua kebutuhan.

## 4. Kesimpulan

Web, Desktop, dan Mobile mempunyai keunggulan dan keterbatasan masing-masing. Web unggul dalam kemudahan akses melalui browser, Desktop dalam integrasi dengan komputer, sedangkan Mobile dalam mendukung penggunaan pada perangkat bergerak. Pemahaman terhadap karakteristik tersebut membantu pengembang memilih platform yang tepat.
